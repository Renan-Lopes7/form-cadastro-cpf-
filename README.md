# form-cadastro-cpf

Formulário de cadastro com validação de CPF, usuário e senha.

## 🔗 Demo

https://renan-lopes7.github.io/form-cadastro-cpf-/

## 📖 Sobre

Projeto desenvolvido durante os estudos de **Programação Orientada a Objetos (POO)** com JavaScript, como parte do curso de JavaScript/Node.js. O objetivo foi praticar conceitos de POO como classes, métodos estáticos e encapsulamento com `Object.defineProperty`, aplicados em um caso real de validação de formulário.

## Funcionalidades

- Validação de CPF com algoritmo dos dígitos verificadores
- Validação de usuário (3 a 12 caracteres, apenas letras e números)
- Validação de senha (3 a 12 caracteres)
- Confirmação de senha
- Máscara automática no campo CPF
- Mensagens de erro inline por campo

## Tecnologias

- HTML
- CSS
- JavaScript (Vanilla)

## Como usar

Basta abrir o `index.html` no navegador.
